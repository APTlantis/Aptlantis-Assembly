# Aptlantis Assembly

A dark SiYuan theme adapted from the Aptlantis x86 Assembly logo palette.

Assembly uses layered graphite editor surfaces and restrained warm-metal highlights to echo the logo's low-level programming and machine-room feel. Softer reading text, steel-toned selection, and selective brass accents keep long sessions calm without losing the industrial identity.

## Source Material

- Logo: `assembler-refs/apt-assembly-logo.png`
- Extracted 16-color palette: `assembler-refs/apt-assembly-logo-palette.txt`
- JetBrains reference theme: `assembler-refs/apt-assembly-theme.icls`

## Package Files

- `theme.json`: SiYuan package metadata
- `theme.css`: theme variables and common SiYuan surface styling
- `icon.png`: marketplace icon generated from the Aptlantis Assembly logo
- `preview.png`: package preview image generated from the logo and palette
